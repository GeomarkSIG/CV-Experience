## 📦 Plugins QGIS développés

### FibreDetection — Détection d'une fibre
Plugin PyQGIS avec interface Qt Designer. Sélection d'un site raccordé (EDSI), mise en surbrillance de la fibre rattachée avec synopsis complet : boîtiers, points techniques, longueur câble, sous-tubage.

### FibreDistribution — Synopsis réseau / Détection cœur de réseau
Plugin PyQGIS de visualisation des fibres de distribution par cœur de réseau (Mondon, Local Déporté, Mairie, CTC). Rubber bands colorés par préfixe `codeville`, zoom automatique sur l'emprise active, comptage des fibres par cœur.
